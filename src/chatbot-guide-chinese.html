🤖 自建班级聊天机器人：免费，约 30 分钟

做一个像 Prompt Library 助手那样的聊天机器人，但回答的是你自己的资料：常见问题、评分标准、教学进度。使用 Dify 和免费的 NVIDIA Build API 密钥，无需编程。

无需编程 免费密钥 手机可用
主页 / 参考资源 / 自建聊天机器人

✅ 开始之前

Dify 是一个免费的无代码工具，可以把你的文件变成聊天机器人。NVIDIA Build 提供免费的 API 密钥，也就是机器人用来写答案的“大脑”。你需要准备：

  • 一个电子邮箱（用来注册 NVIDIA Build 和 Dify）。
  • 1 到 3 份你自己的资料（简短的常见问题、评分标准、教学进度）。文本、Word、PDF 或 Markdown 都可以。
  • 一台电脑用于设置（做好的机器人可以在手机上使用）。
⚠️ 绝对不要上传学生资料。不要放姓名、身份证号码、成绩、电话号码或照片。只用一般性的资料，并遵守学校的 AI 与个人资料保护（PDPA）规定。

第 1 步：获取免费的 NVIDIA Build 密钥（5 分钟）

  1. 打开 build.nvidia.com 并登录 前往 build.nvidia.com 创建免费账号。NVIDIA 可能会要求验证手机号码。
  2. 选择模型 打开模型列表，选一个小而快的对话模型。进入它的页面，点击 View Code（或 “Get API Key”）。记下 model= 后面的模型 ID，例如 nvidia/nemotron-3.5-bolt-e4b。模型名称会随时间变化，所以请务必从页面上复制 ID。
  3. 生成并复制你的 API 密钥 点击 Generate API Key。密钥以 nvapi- 开头，只显示一次。请贴到私人笔记里。不要把密钥放进网页、聊天窗口或截图。
💡 使用限额：免费方案有请求次数限制，而且可能会变动。在与全校分享机器人之前，请先到 build.nvidia.com 查看最新限额。

第 2 步：注册 Dify 并连接 NVIDIA（10 分钟）

  1. 注册 Dify Cloud 前往 cloud.dify.ai，用邮箱或 Google 账号注册。免费方案足够试用。请查看最新方案限额。
  2. 安装 “OpenAI-API-compatible” 插件 打开右上角的 Plugins，搜索 OpenAI-API-compatible，点击 Install。这个插件让 Dify 能连接任何兼容 OpenAI 的服务，包括 NVIDIA。
  3. 添加 NVIDIA 模型 点击头像，选择 Settings，再选 Model Provider。在 OpenAI-API-compatible 下选择 Add Model，按下表填写。不同版本的标签可能略有差异。

第 3 步：把你的资料交给机器人（5 分钟）

  1. 创建 Knowledge（知识库） 打开 Knowledge，点击 Create Knowledge，上传你的文件。
  2. 选择索引设置 选 Economy（关键词搜索）。它免费，也不需要额外的模型。分段设置保持默认即可。
  3. 把资料写成小段落 机器人一次只会找出一个段落。请用简短的标题，一个主题一段，例如 ## 如何提交作业，后面跟 3 到 5 行。资料清楚，答案才清楚。

第 4 步：创建聊天机器人（5 分钟）

  1. 创建应用 进入 Studio，点击 Create from Blank，选择 Chatbot，并取个名字（例如“中四科学小助手”）。
  2. 选择模型 在右上角选择你刚添加的 NVIDIA 模型。把 Temperature 设为 0.3（更稳定，较少编造），Max tokens 设为 1200。有些模型会先“思考”，上限太低会导致回复为空。
  3. 连接你的知识库 在 Context 下点击 Add，选择第 3 步做好的知识库，并把 Top K 设为 4。
  4. 贴上指令 把下面的模板复制到 Instructions 框里，并填写【括号】中的内容。

你是【学校 / 班级 / 科目】的班级助手。
只能根据检索到的内容（我的资料）回答。
如果资料里没有答案，请说：“我在老师的资料里找不到这个，请询问你的老师。”
- 用学生最新一条消息所使用的语言回复（中文、Bahasa Melayu 或 English）。
- 回答不超过 150 字，用适合【中几 / 几年级】的简单语言。
- 绝对不要编造事实、日期、成绩或规定。
- 如果问题与【科目】无关，请礼貌地回复：“我只能回答【科目】的问题。”
- 不要索取或储存个人资料（姓名、身份证号码、电话号码）。
💡 为什么要写“只能根据我的资料回答”？免费的小模型擅长引用你的资料，但被问到一般常识时可能会乱猜。这一条规则就能避免大部分错误答案。

第 5 步：用 5 个问题测试（5 分钟）

使用右侧的预览面板，依次提问：

  1. 一个你的资料里有清楚答案的问题。
  2. 用 English（或 Bahasa Melayu）问同一个问题。回复应该使用该语言。
  3. 一个你的资料里没有答案的问题。它应该回答找不到。
  4. 一个无关的问题（“法国的首都是哪里？”）。它应该礼貌地拒绝。
  5. 用和资料不同的说法提问。如果答不出来，就把这些说法加进资料里。

第 6 步：分享给学生

  1. 发布（Publish） 点击 Publish，再点 Update。每次修改资料或指令之后，都要重新发布。
  2. 分享链接（最简单） 选择 Run App 并复制网址，通过 WhatsApp 或 Google Classroom 发给全班。手机上也能使用。
  3. 或在网页上加一个聊天气泡 选择 Embed Into Site，把代码复制到你的 Google Site、Blogger 或学校网页中，放在页面结尾之前。Prompt Library 的助手就是这样运作的。
🔒 安全检查清单
  • 你的 nvapi- 密钥只保存在 Dify 里，不会出现在嵌入代码中。
  • 链接和气泡代码是公开的：任何拿到的人都可以聊天，并用掉你的免费额度。只分享给你的班级。
  • AI 可能出错。重要的答案（日期、成绩、规定）请对照你的资料核实。
  • 如果不小心把密钥贴到聊天或网页上，请立刻到 build.nvidia.com 删除并重新生成。

💻 备用方案：在自己的电脑上运行 Dify

Dify 是开源软件。如果 Dify Cloud 不适合你，可以用 Docker 在自己的电脑上运行，完全免费且更私密。大约需要 30 分钟，并需要一些命令行基础，建议请学校的 ICT 老师协助。请按照 docs.dify.ai 的官方指南操作。上面的第 1 至第 6 步保持不变。
